## 🎯 Objectives

Through this project, you will:

* 🧑‍💻 Apply **functional programming** principles
* 🌐 Develop **asynchronous client & server logic**
* 🔄 Implement **reactive patterns** for the UI
* 🧪 Write **unit tests** with industrial-level standards

---

## 🛠️ General Instructions

* 📜 Use **latest JavaScript** everywhere
* ❌ No `this` in client code (except for custom `Error` subclasses)
* 🎨 Layouts with **Flexbox / Grid** (no `<table/>`, no canvas, no SVG)
* 🧩 **Pure functions** for game logic
* 🖥️ **OOP with prototypes** on server-side

✅ Unit tests must cover:

* 70% of **statements, functions, lines**
* 50% of **branches**

---

## 🎮 Mandatory Features

* Classic **Tetris mechanics** 🧩
* Multiplayer mode where **clearing lines sends penalty lines** to opponents 💥
* Each field: **10x20 grid**
* **Spectrum view** of opponents in real-time 🔍
* Winner = **last player standing** 🏆

🎮 Controls:

* ⬅️ ➡️ Move
* ⬆️ Rotate
* ⬇️ Soft drop
* ␣ Hard drop

---

## 🧩 Technical Details

* 🖥️ **Client/Server architecture**
* ⚡ **Node.js + socket.io** for communication
* 🌍 Client = **SPA** (React / Vue recommended)
* 📦 State management via **Redux**
* 📂 Boilerplate repo available: [red\_tetris\_boilerplate](https://github.com/redpelicans/red_tetris_boilerplate)

---

## 🧪 Testing

* 🚦 Unit tests are mandatory
* 🧮 Coverage:

  * 📊 70% Statements, Functions, Lines
  * 🌳 50% Branches
* 🔒 No secrets in repo! Use `.env` (gitignored)
